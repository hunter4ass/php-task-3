# Медицинская информационная система расписания приёмов

## Быстрый старт
```bash
git clone <repo>
cd htdocs
composer install
```

## База данных
1. Убедитесь, что MySQL запущен и пользователь `root` доступен без пароля (либо поправьте `config/db.php`).
2. Выполните скрипт `database/schema.sql` — он создаст структуру и базовые данные:
   ```bash
   mysql -u root -p < database/schema.sql
   ```
3. Дефолтные учётные записи:
   - Администратор: `admin / admin123`
   - Врач: `dr-smirnova / doctor123`
   - Пациент: `patient-petrov / patient123`

## Основные возможности
- Ролевой доступ (администратор, врач, пациент) к маршрутам и интерфейсам.
- Управление расписанием приёмов: создание, редактирование, фильтрация, полнотекстовый поиск по пациентам/врачам/услугам.
- Загрузка сканов/фото к записи на приём (папка `public/uploads/appointments` создаётся автоматически).
- Регистрация пациентов и добавление сотрудников администратором.
- Набор прикладных валидаторов (`phone`, `date_before`, `date_after`, `enum`, `image`) интегрирован во все формы.
- CSRF, trim и sanitizing middleware для всех POST-запросов.
